RUANG — JURNAL & JADWAL

Cara memasang di GitHub Pages:
1. Buka repositori GitHub bernama ruang-jurnal.
2. Unggah semua isi folder ini ke lokasi utama repositori (root).
3. Pastikan file utama bernama index.html.
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses selesai. Alamat website akan muncul di bagian GitHub Pages.

Catatan penting:
Website bisa dibuka dari perangkat mana pun melalui internet. Namun jurnal dan jadwal versi ini masih disimpan di browser/perangkat tempat data dibuat (localStorage), jadi belum otomatis tersinkron antarperangkat. Gunakan perangkat dan browser yang sama untuk melihat data yang sama.

File ini juga mendukung pemasangan sebagai aplikasi web (PWA) dan cache offline setelah pertama kali dibuka melalui HTTPS.
